U-CARE

Uncertainty-Aware Cross-Modal Attention Network with Explainable AI for Trustworthy Retinal Disease Classification

U-CARE is a deep learning framework for retinal disease classification using multimodal retinal imaging. The framework combines Fundus and OCT features, cross-modal attention, uncertainty estimation, and Explainable AI (XAI) to support trustworthy AI-based retinal analysis.

Key Features
🩺 Multimodal Fundus + OCT analysis
🔀 Cross-Modal Attention
🎯 Uncertainty estimation using Monte Carlo Dropout
🔍 Explainable AI using Grad-CAM / EigenCAM
📊 Class-balanced evaluation and performance analysis
👁️ Patient-level multimodal learning
Datasets

Experiments are conducted using retinal datasets including ODIR-5K, Retinal OCT, and MultiEYE.

Project Status

🚧 Under active research and development

The repository currently contains the training and experimental code. Multimodal integration, extensive evaluation, and final experiments are ongoing.
